# Style additions

The style standard is [`../../content-fence/references/economist-writing-style-guide.md`](../../content-fence/references/economist-writing-style-guide.md). This file holds only what that guide lacks: extra banned words, common usage errors, and KB's own voice rules. Read both.

Length is a diagnostic, not a limit. Flag a sentence or paragraph for what it costs the reader, never for its word count alone.

## UNIVERSAL

### Banned words, beyond the Economist list

Corporate and AI-flavoured words. Flag them when a plainer word exists:
align, crushing it, deep dive, delve, democratize, disruptive, drive/driving, ecosystem, elevate, empower, flywheel, foster, garner, guru, growth-hack, harness, human capital, hustle (grind sense), innovative, journey, landscape, ninja, north star, optimize, realm, reimagine, robust, rockstar, scalable, seamless, streamline, synergy, tapestry, testament, 10x, unlock, unleash, unparalleled, world-class.

### Common usage errors

Alternate = every other. Alternative = one of two. · Among = three or more. Between = two. · Convince someone of a fact; persuade someone to act. · Critique = noun. Criticise = verb. · Disinterested = impartial. Uninterested = bored. · Cost-effective = good value; if it is cheap, say cheap. · Enormity = a great wrong, not immensity. · Practicable = feasible. Practical = useful. · Presently = soon, not "at present". · Systemic = of a whole system. Systematic = methodical. · Data and media are plural. · Strategy/strategic: only in a real military or competitive-positioning sense. · Issues: say "concern" or "number", whichever is meant. · Challenge: drop it and name the actual problem.

### Openers and dashes

- Banned openers: "In a world where..." and "In today's fast-paced...".
- No em dashes. Use a comma, colon, or new sentence.

## KB VOICE (KB-ECOSYSTEM MODE ONLY)

- Currency: ₹, not "Rs". Add a dollar conversion in brackets if it helps a non-Indian reader.
- Indian numerals: lakhs, crores. Add millions or billions in brackets for a global reader.
- Person: "I", not "we", unless the action was genuinely collective.
- Contractions are fine; don't overdo them.
- Spell out abbreviations on first use.
