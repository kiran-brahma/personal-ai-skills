## Unreleased — Owner-skill review for current models, batch 1

The owner's skills were written for older models. This batch removes what current models do unprompted or that is stated more than once.

- **Removed `business-problem-solving`.** It restated general consulting method (problem definition, Cynefin, issue trees, MECE, impact/ease ranking) that current models apply unprompted, so it failed the `decide-skills` "would only restate general competence" test. A broad operating problem now gets no dedicated skill; the agent structures it directly and hands a concrete choice to [`decision-navigator`](../library/decision-navigator/SKILL.md). Removed from the `business` profile, the registry package, and the index. Eval: `business-workflows.md` Case 4 updated.
- **One style source.** [`content-fence/references/economist-writing-style-guide.md`](../library/content-fence/references/economist-writing-style-guide.md) is now the only Economist style guide. `musings-reviewer/references/economist-style.md` (a condensed copy) is deleted, and [`musings-reviewer`](../library/musings-reviewer/SKILL.md) reads the shared guide's named sections. [`cognitive-editor/references/style-guide.md`](../library/cognitive-editor/references/style-guide.md) shrinks from about 2,500 words to 330, keeping only what the shared guide lacks: extra banned words, common usage errors, banned openers, em dashes, and KB voice rules. Its hard "3 sentences per paragraph, 20 words per sentence" limits are gone; they contradicted the skill's own rule that length is a signal, not a failure.
- **[`cognitive-editor`](../library/cognitive-editor/SKILL.md) trimmed** from about 2,100 to 1,350 words. Removed the persona framing, the "What you do not do" and "One governing principle" sections that repeated the opening, and the Flesch 60–70 target, which the agent could not measure. The audits, modes, series checks, and report format are unchanged. New rule: report only material problems, and write "No material issues." for a clean audit instead of manufacturing a finding. Effect: shorter reports on good drafts, less nitpicking. Eval: `writing-workflows.md` Case 16.

#### Fixed `bin/skills-sync upstream` and `adopt` on binary files

- Both decoded upstream files as UTF-8 text, so `upstream` crashed with `UnicodeDecodeError` on a binary file in a vendored skill (first seen on `heygen-hyperframes`), and `adopt` would have done the same.
