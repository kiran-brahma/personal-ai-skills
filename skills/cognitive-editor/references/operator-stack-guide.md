# The Operator Stack — Cognitive Upgrade Guide

## Core Constraint (Non-Negotiable)

All intelligence upgrades must be:
- Reversible
- Sandboxed
- Logged
- Separable from live operations

No exploratory thinking ships into decisions. No operational decisions are speculative.

---

## The Four Cognitive Modes

All work inside The Operator Stack must clearly belong to ONE and only ONE mode.

### Mode 1: Unstable Frames (Exploration Mode)

**Function:** Raise abstraction ceiling without consequence.

Allowed: half-formed ideas, contradictions, weird analogies, domain transfers, speculation without proof.

Forbidden: conclusions, advice, publishing intent, operational authority.

**Success metric:** Did this surface a new way of seeing, even if wrong?

This layer is private. Exists to think dangerously where failure is cheap.

---

### Mode 2: Field Notes (Reasoning Mode)

**Function:** Pressure-test thinking against reality.

Allowed: post-incident analysis, causal chains, trade-offs, counterfactuals.

Required for every Field Note:
- What broke
- Why my previous model failed
- What signal I missed
- What must now be true

Forbidden: polished narrative, universal claims, audience optimisation.

**Success metric:** Did this reduce my future error rate?

---

### Mode 3: Operator Essays (Frozen Judgment Mode)

**Function:** Lock in judgment that has survived pressure.

Allowed: invariants, decision rules, non-obvious truths, hard boundaries.

Required:
- Trigger condition
- Mandated action
- Known exception (if any)

Forbidden: exploration, hypotheticals, soft language.

**Every essay must answer:** What decision does this permanently remove from my future?

---

### Mode 4: O9X Build Logs (Execution Mode)

**Function:** Translate judgment into systems.

Allowed: process design, interfaces, checklists, automation logic.

Forbidden: philosophy, lessons, reflection.

**Success metric:** Did this reduce dependence on human judgment?

---

## Mandatory Abstraction Upgrade

For every major Operator Essay, run this internal exercise:

1. Write the grounded conclusion (what I know is true).
2. Derive ONE forward abstraction not yet tested.
3. Label it explicitly: **UNPROVEN HYPOTHESIS**

This hypothesis cannot ship as truth, cannot guide decisions, must be tracked.

---

## Judgment Index (Compulsory)

Each frozen judgment entry must include:
- Name of judgment
- Origin (essay / incident)
- Trigger condition
- Mandated action
- Known exceptions

If an idea cannot be indexed, it is not real judgment.

---

## Recursion Rule

Before creating anything new, ask:
- What have I already written that this builds on?
- What judgment can be sharpened instead of adding novelty?

99%+ intelligence compounds by recursion, not volume.

---

## Personal Success Metrics

Every piece must improve at least one:
- Fewer future decisions
- Earlier detection of fragility
- Faster containment of failure
- Reduced emotional load during pressure

If it doesn't harden me, it doesn't belong.
